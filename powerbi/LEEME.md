# Power BI

Subir aquí **SmartRetail.pbix** (modelo OLAP y dashboard de cuatro páginas).

- Modo: Importación, conectado a la base `SmartRetail` de SQL Server (esquema `dw`).
- 14 medidas DAX: Ventas Totales, Numero Pedidos, Ticket Promedio, Tasa Cancelacion,
  Tiempo Promedio Entrega, Pct Entregas a Tiempo, Meta OTD, Entregas por Fecha Entrega,
  Unidades Vendidas, Pct Ventas Cruzadas, Stock Disponible, Productos Agotados,
  Productos Bajo Stock y Rotacion Inventario.
- Jerarquías: Calendario, Geografía y Catálogo.
